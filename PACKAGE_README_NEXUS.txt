Passive Pals (UE4SS mod package for Nexus Mods)
===============================================

Pals outside your control stop attacking you on sight, stop fleeing when you
come near, and always fight back when actually attacked, regardless of level
difference. Humans keep their vanilla behavior by default. Your own pals and
base workers are untouched.

Requires UE4SS (RE-UE4SS Okaetsu Experimental-Palworld line). This zip carries
the full game path: extract it into the Palworld install folder (the one
containing Palworld.exe and Pal\) so that
Pal\Binaries\Win64\ue4ss\Mods\PassivePals\Scripts\main.lua exists.

Configuration: edit Scripts\settings.lua inside that folder and save it. The
change applies within a couple of seconds while you play; no restart. The
file documents everything: behavior profiles, assignment by kind
of character, per-preset and per-species assignment, the petting switch,
logging, and the full reaction glossary.
