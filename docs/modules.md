# Modules

Per-file responsibilities.

| Path | Holds |
|---|---|
| `Info.json` | Package manifest: identity, version, UE4SS dependency, and two Lua install rules (client, plus an `IsServer: true` rule that installs `Scripts\` on a dedicated server too). |
| `Scripts/main.lua` | Engine: resolves each preset CDO (lazy-retry poll), applies the overrides, logs one line per preset to `UE4SS.log`, self-disables per preset when a symbol is missing. No game symbol names. Every setting-derived value lives in one `state` table that `buildState` rebuilds, so `applyLive` can run both layers again on an edit. |
| `Scripts/livecfg.lua` | The settings watcher: re-reads `settings.lua` as text on a `LoopAsync` interval (never `require`, whose result is cached in `package.loaded`), parses a changed file with `load(text, name, "t", {})` in an empty environment, and calls back only on a file that parses to a table. Unreadable or broken files warn once and leave the settings in force. Touches no UObject; the callback hops to the game thread itself. |
| `Scripts/config.lua` | All game symbols: the eleven preset paths, `EPalAIResponseType` values, the human-only preset list (`VillageNPC`, `Kill_All`), and `presetGroups`, which files each of the eleven presets under exactly one of the seven kind-of-character settings. Holds no player setting: everything a player edits lives in `settings.lua`. |
| `Scripts/settings.lua` | The user-edited file and its own manual, re-read live: behavior profiles (built-in, a ready-made `custom` with all eight slots spelled out, and any the user adds), assignment at pal-default / human-default / kind-of-character / per-AI-preset / per-species levels, the petting switch, logging level, the live-reload interval, retry timing, reaction-value glossary, authoritative preset carrier counts. Reinstalls with defaults on mod update. Every player-facing knob is a literal scalar at depth three or shallower, each carries a one-sentence trailing comment, and each fixed value set or range is stated in the comment line directly above it: that is what makes the whole file editable from Universal Config Manager's options tab. Keep it pure data (no calls, no concatenation, no identifiers as values) or it drops out of that tab. |
| `Scripts/SpeciesNames.tsv` | Generated from the game's own name tables: 1,523 pal display names in the other sixteen languages, mapped to row id. Loaded after the English pass, so an English spelling always wins a collision. Regenerate after a game update alongside the file below. |
| `Scripts/SpeciesReference.tsv` | Generated from the game's own tables: every pal row id, its English display name (725 of 753 resolved; the 28 without names are unreleased species), its vanilla AI preset, its `ZukanIndex` and its `BPClass`. A species key resolves through `BPClass`, because 33 rows do not name their Blueprint after themselves. Ships with the mod for `bySpecies` users. Regenerate via `..\.Tooling\PalDataExtract` after a game update. |
| `tools/test/` | The offline suite: `run_tests.lua` runs `suite_livecfg`, `suite_plan`, `suite_layers` and `suite_docs` against the stubbed engine in `engine.lua`. |
| `tools/deploy.ps1` | `-Package` stages the Dev identity (`PassivePalsDev`); `-Unstage` reverses; `-Release` writes both publishable packages to `out\` (Steam loader package and full-game-path Nexus zip, Palpedia Enhancer pattern). |
| `PACKAGE_README.txt`, `PACKAGE_README_NEXUS.txt` | The in-zip readme for each site. |
