# Design notes

How the settings layers and the live reload work.

- `levelDifference` rewrites the fight axis across whichever profile a character ended up with: `profile` leaves each profile as written, `respect` turns every `fight_always` into `fight_if_winnable` so the engine's strength check decides, `ignore` does the reverse. It is the one knob that composes with every assignment level instead of sitting at one of them.
- `Scripts\settings.lua` drives everything through behavior profiles (eight reaction slots each; built-ins, a ready-made `custom`, plus user-defined) assigned at five levels, most specific last: pal default, human default, kind of character (the seven `config.presetGroups` settings, which partition all eleven presets), per AI preset, per species (the three `speciesRules` slots and the open `bySpecies` table, the table winning on a tie).
- The preset layers rewrite shared preset CDOs at load; the species layer constructs a per-sensor preset object (outer: the sensor, so lifetime follows it) from snapshotted vanilla values when a configured species first runs a sense decision, via the verified sense hook.
- `Scripts\settings.lua` is watched while the game runs (`Scripts\livecfg.lua`, every `liveReloadSeconds`, default 2): a saved edit re-applies both layers within seconds, no restart, whether the file was edited in a text editor or by another mod's settings screen. Every apply starts from the snapshotted vanilla values, so a rule that a live edit dropped reverts instead of sticking; sensors the species layer already reached go back to their shared preset and decide again on their next sense. Only `pollSeconds` is not live (it sets the interval of a wait that normally ends seconds after launch).
- The `smart_defender` built-in profile is threat assessment: fight if winnable, flee when outmatched, locomotion-native flight. Winnability comes from the engine's own `CheckCombatableByLevelDiff` gate (`fight_if_winnable`), relative-strength tiers from the vanilla Greater/Equal/Smaller slots, and fleeing pals already use their species' native locomotion.
